    컬리 계정 연결

    미연결

    아이디·비밀번호로 한 번만 연결하면, 이후에는 암호화된 로그인 세션으로 자동 실행합니다.

    🔒 비밀번호는 저장하지 않습니다. 로그인 성공 후 받은 세션만 AES-256-GCM 으로 암호화해 보관해요.

    로그인 보안(reCAPTCHA) 때문에 안 될 때: 세션 직접 가져오기 이미 로그인된 내 컴퓨터 브라우저의 세션을 그대로 옮겨요

    클라우드·해외 서버에서는 컬리 로그인에 붙은 구글 reCAPTCHA 가 봇으로 판단해 비밀번호가 맞아도 거부할 수 있어요. 그럴 때 내 컴퓨터 브라우저(크롬·엣지)에서 로그인된 세션을 복사해 오면 로그인 없이 담을 수 있어요. (아이폰 사파리·컬리 앱에서는 보안상 복사할 수 없어요.)

    kurly-state.json · storage-state.json
    1. 컴퓨터 브라우저에서 컬리에 로그인한 상태로 개발자도구(F12 또는 ⌥⌘I) → Network 탭을 엽니다.
    2. 요청 하나(예: main)를 골라 Request Headers 의 cookie: 줄을 통째로 복사해 위 칸에 붙여넣습니다.
    3. 로컬 kurly-auto-cart 를 쓰셨다면 .state/kurly-storage.json 을 그대로 올려도 됩니다.

    주소창에서 document.cookie 를 복사하면 HttpOnly 쿠키(ksi·krt) 가 빠져 실패해요. 반드시 Network 탭의 cookie: 요청 헤더를 복사해 주세요.

    🔒 붙여넣은 세션은 확인 후 AES-256-GCM 으로 암호화해 보관하고, 평문은 남기지 않아요.
